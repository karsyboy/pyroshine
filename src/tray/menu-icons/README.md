# Tray menu icons

White alpha masks of [Material Icons](https://fonts.google.com/icons) by
Google, licensed under the [Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0),
taken from `@mui/icons-material` (MIT), the same icons the web interface uses.
The tray tints them to the desktop's menu text color at startup.

Regenerate with `python3 web/scripts/generate-icons.py` (needs `npm ci` in
`web/`, Pillow and `rsvg-convert`).
